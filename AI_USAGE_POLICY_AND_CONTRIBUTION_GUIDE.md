# AI usage policy for this repository (and somewhat a contribution guide)

Regardless of whether you are using AI or not, the same quality standards should be applied. The word "slop" is not what I want to achieve with this project, so AI assisted submissions and edits should be reviewed with the same care as human ones.

However, clarity is required, if you used an AI assistance in code writing, debugging or anything that will be shipped to the end user, you must state what AI model or service was used and, preferrably, how much it affected the end result, the code itself.

If AI assistance is used (even for a line of code), you should state the above points in the README's "AI disclosure and usage policy" section.

You must understand the code you are submitting, since it's human's duty to maintain the code in the future.

You must understand what's going on in the code (understand the subject's area).

Before submitting changes you should test them, automatically (by writing and running unit-, integration- or e2e-tests) or manually (refer to the [Full manual testing pipeline](./docs/FULL_MANUAL_TESTING_PIPELINE.md) that I wrote for the ideas of how to test it).

Basically: do good, don't do harm.

Also, image generation is currently not allowed, I personally prefer to draw the icons myself.
